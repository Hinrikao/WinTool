Fixes

Repairs for common Windows problems. Each one asks first and writes what it does to the log.

Reset Windows Update

Stops the update services, renames the SoftwareDistribution and catroot2 folders so Windows builds fresh ones, then starts the services again. Use it when updates fail or stay stuck.

May need a restart

Reset network

Clears the DNS cache and resets Winsock and the TCP/IP stack for IPv4 and IPv6. Use it when websites do not load while the connection looks fine. Static IP settings may need to be entered again.

May need a restart

Repair system files

Runs DISM RestoreHealth to repair the Windows component store, then System File Checker to fix protected system files. This can take a while.

No restart required

Repair winget

Installs Microsoft's WinGet PowerShell module and runs its repair command, which reinstalls App Installer and restores winget when installs fail.

No restart required
