Animations

Proposed motion for WinTool. All of it uses opacity or transform only, keeps every control in a fixed slot, and can be done with WPF storyboards.

Page switch
150 ms fade and an 8 px slide on the page only. Opacity and transform, so the sidebar, title, and status bar never move.
Home
Install
Sidebar pill
180 ms slide of the 3 px accent bar and the soft fill between nav rows. Items stay 40 px tall in a fixed list.
Card hover
150 ms lift of 2 px and an accent border. The 1 px border is always there, so width and height do not change.
Toggle thumb
120 ms slide of the 14 px thumb on a 40×20 track. The control size is fixed; only left position animates.
Progress shimmer
A looping gradient on the 8 px status bar track. The bar stays in its reserved slot and is hidden by opacity, not by collapsing height.
Score ring
600 ms stroke-dashoffset draw on the Home ring when analysis finishes. The 196 px slot and the 28 px score stay put.
Checkbox fill
100 ms accent fill and check mark fade inside the 20 px rounded square. No focus ring, no size change.
Fixed slots
Home actions swap Fix / Review in a 76 px slot. Install buttons swap Install / Update / Open in a two-slot 32 px row. Hidden buttons stay invisible, not removed.
