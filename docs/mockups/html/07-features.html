Windows features

Optional parts of Windows. Ticked means on. Change the ticks and press Apply. Windows needs a restart after a change.

3 features are on. 1 change is pending.
Hyper-V
Microsoft's virtual machine platform and Hyper-V Manager. Needs Windows 11 Pro and virtualization in the firmware.
Off
Windows Sandbox
A throwaway desktop for trying unknown apps. Everything inside is deleted when it closes.
Off
Windows Subsystem for Linux
Runs Linux distributions such as Ubuntu. Turn on Virtual Machine Platform too for WSL 2.
On
Virtual Machine Platform
The virtualization layer WSL 2 and Android apps need.
On
Windows Hypervisor Platform
Lets other virtualization apps, such as some Android emulators, run on top of Hyper-V.
Off
.NET Framework 3.5
Includes .NET 2.0 and 3.0. Older apps and games ask for it.
On
NFS client

Off

An old networking component some games from the early 2000s still need.

Off
