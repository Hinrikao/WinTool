Drivers and updates

WinTool uses Windows Update and links to the graphics vendor. It does not install driver cleaner or booster tools.

Update mode

WinTool only writes Windows Update policies. Default removes them again.

Current mode: Security updates only
Default
Windows installs updates on its own schedule and removes WinTool policies.
Security updates only
Monthly security updates install four days after release. Feature updates wait.
Disabled
Stops Windows Update completely. The PC gets no security fixes.
